## 📖 Описание

Плагин **Notification Center** для клиентов **exteraGram** и **AyuGram**.

Кастомизация и фильтрация уведомлений от каналов и групп.

---

## 📥 Установка

1. Перейдите во вкладку [**Releases**](https://github.com/MaxExteraPlugins/notification_center/releases/latest).
2. Скачайте файл плагина `notification_center_v5.0.0.plugin`.
3. Отправьте файл в Telegram (в «Избранное») или откройте его через проводник в exteraGram / AyuGram.
4. Нажмите на сообщение с плагином и выберите **«Установить плагин»**.

---

## 📋 Совместимость

* **exteraGram:** `>= 12.10.6`
* **AyuGram:** `>= 12.10.6`
* **Plugin SDK:** `>= 1.4.3.3`
