## 📖 Description

**Notification Center** plugin for **exteraGram** and **AyuGram** clients.

Discord-style notification center: collects and stores all mentions and replies to your messages.

---

## 📥 Installation

1. Navigate to the [**Releases**](https://github.com/MaxExteraPlugins/notification_center/releases/latest) section.
2. Download the `notification_center_v5.0.0.plugin` file.
3. Send the file to your Telegram Saved Messages or open it via file manager in exteraGram / AyuGram.
4. Tap the file in Telegram and choose **"Install plugin"**.

---

## 📋 Compatibility

* **exteraGram:** `>= 12.5.1`
* **AyuGram:** `>= 12.5.1`
* **Plugin SDK:** `>= 1.4.3.3`
